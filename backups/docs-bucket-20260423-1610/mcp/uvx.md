# Installing `uv` for uvx-based MCPs (macOS)

The Google Analytics, AWS and Metabase MCPs use `uvx` instead of `npx`, so you need to install `uv` first. Below are the macOS installation instructions.

## Install without Homebrew

```
curl -LsSf https://astral.sh/uv/install.sh | sh
```

## Install with Homebrew

```
brew install uv
```
