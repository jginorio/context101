# Example product

Replace this file with a description of one of your team's products. The goal is to give an agent enough context to answer "what is X?" without you having to paste the same backgrounder into every chat.

A useful product page covers:

- **What it is** — one or two sentences a non-technical teammate could repeat.
- **Who uses it** — the primary audience and how they discover it.
- **Where it lives** — domains, repositories, primary databases, dashboards.
- **What's currently true** — recent traffic, active accounts, anything that dates fast (mark with the date you wrote it).
- **What's deliberately *not* in scope** — common confusions worth pre-empting.

Keep one file per product so retrieval can scope cleanly.
